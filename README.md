Next.js 16 (App Router) + Tailwind CSS 4. Recriação de https://aw-tecnologia.vercel.app/ mantendo copy e identidade, sem dependência de lib de scroll externa.

```bash
npm install
npm run dev     # desenvolvimento
npm run build   # produção
```
